A one-line entry for the "One Line, One Laugh" bounty on make.fun: the password is literally the word "incorrect", so the computer's own error message becomes a true statement every time its owner forgets it. Short, fast, and it lands without explaining itself — the line is the whole entry, all 144 characters of it.

## Run it

```sh
python3 main.py
```

This prints the line and writes it to `/output/entry.txt` (no trailing newline).
